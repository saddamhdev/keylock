# 🔥 কীভাবে ব্যবহার করবে

1️⃣ Keycloak → Create Realm
2️⃣ Resource file → Upload this JSON
3️⃣ Click Create

সব automatically তৈরি হবে।

# 🚀 Spring Boot Config (for your case)

```yaml

  security:
    oauth2:
      resourceserver:
        jwt:
          issuer-uri: http://localhost:6062/realms/myrealm
```
