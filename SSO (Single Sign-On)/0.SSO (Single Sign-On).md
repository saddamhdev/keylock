SSO (Single Sign-On) হলো এমন একটি authentication system যেখানে **একবার login করলে অনেকগুলো application ব্যবহার করা যায় আবার login না করেই**। 🔐

সহজভাবে বললে:

👉 **One login → Multiple systems access**

---

## 1️⃣ Example (বাস্তব উদাহরণ)

ধরো তুমি Google এ login করেছ।

তারপর তুমি যদি যাও:

* Gmail
* YouTube
* Google Drive
* Google Docs

এগুলোতে **আবার login করতে হয় না**।

কারণ Google **SSO ব্যবহার করে**।

---

## 2️⃣ Traditional Login vs SSO

### ❌ Without SSO

প্রতিটি system এ আলাদা login করতে হবে।

```
User → Login → App 1
User → Login → App 2
User → Login → App 3
```

Problems:

* অনেক password
* security risk
* user experience খারাপ

---

### ✅ With SSO

```
User
  ↓
Login once (SSO Server)
  ↓
App 1
App 2
App 3
```

User **একবার login করলে token দিয়ে সব app access করতে পারে**।

---

## 3️⃣ SSO Architecture (Simple)

```
User
   ↓
SSO Server (Identity Provider)
   ↓
Access Token
   ↓
Application / Services
```

Components:

| Component               | Meaning              |
| ----------------------- | -------------------- |
| User                    | যিনি login করেন      |
| Identity Provider (IdP) | login system         |
| Service Provider        | যে app ব্যবহার করছে  |
| Token                   | authentication proof |

---

## 4️⃣ Popular SSO Technologies

| Technology     | Use            |
| -------------- | -------------- |
| OAuth2         | Authorization  |
| OpenID Connect | Authentication |
| SAML           | Enterprise SSO |
| JWT            | Token          |

## 8️⃣ Why SSO Important (Enterprise)

Banking / Large systems এ SSO লাগে কারণ:

* 🔐 Central authentication
* 👥 User management easy
* 🧾 Audit log
* 🛡️ Security
* 🚀 Better UX
