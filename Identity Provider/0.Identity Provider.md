তুমি যে স্ক্রিনশটটা দেখিয়েছো এটা **Keycloak** এর **Identity Providers** পেজ।

এই পেজের কাজ হলো:

> **Keycloak এর মাধ্যমে অন্য login system ব্যবহার করা (Identity Federation / Social Login)।**

মানে user **Keycloak এ account না থাকলেও** অন্য provider দিয়ে login করতে পারবে।

---

# 1️⃣ Identity Provider কী?

Identity Provider (IdP) মানে:

```text
User authentication অন্য system করবে
```

Flow:

```
User
 │
 ▼
Keycloak
 │
 ▼
Google / Facebook / GitHub
 │
 ▼
User authenticated
 │
 ▼
Back to Keycloak
```

Keycloak এখানে **identity broker** হিসেবে কাজ করে।

# 3️⃣ Example: Google Login

Flow:

```
User clicks "Login with Google"
      │
      ▼
Keycloak redirects to Google
      │
      ▼
User login in Google
      │
      ▼
Google sends token to Keycloak
      │
      ▼
Keycloak creates local session
```

এখানে Google ব্যবহার করে:

* **OAuth 2.0**
* **OpenID Connect**
