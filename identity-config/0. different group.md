  "enabled": true,
  "displayName": "Banking Dev Realm",

  "loginWithEmailAllowed": true,
  "duplicateEmailsAllowed": false,
  "resetPasswordAllowed": true,

  "roles": {
    "realm": [
      { "name": "CUSTOMER" },
      { "name": "TELLER" },
      { "name": "MANAGER" },
      { "name": "AUDITOR" },
      { "name": "ADMIN" },
      { "name": "SERVICE_ACCOUNT" }
    ]
  },

  "clients": [
    {
      "clientId": "internet-banking-web",
      "protocol": "openid-connect",
      "publicClient": true,
      "redirectUris": ["http://localhost:3000/*"],
      "webOrigins": ["http://localhost:3000"],
      "standardFlowEnabled": true
    },
    {
      "clientId": "banking-backend",
      "protocol": "openid-connect",
      "publicClient": false,
      "secret": "dev-backend-secret",

  ]
}

# 🔥 Real Banking Extra (Production এ থাকে)

Production এ আরো থাকে:

* Require SSL: "all"
* MFA required
* OTP policy
* Audit logging enabled
* HSM integration
* Client secret environment variable থেকে আসে
* SIEM integration (Splunk)
