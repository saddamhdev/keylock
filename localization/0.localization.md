You are on **Realm settings → Localization** in **Keycloak** for your realm `myrealm`.
This section controls **language and translation support** for Keycloak pages.

---

# 1️⃣ What Localization Means

**Localization (Internationalization / i18n)** allows Keycloak to show the UI in **different languages**.

Example:

| User Language | Login Page     |
| ------------- | -------------- |
| English       | Login          |
| Spanish       | Iniciar sesión |
| French        | Connexion      |
| Bengali       | লগইন           |

So users can see the login page in their preferred language.

---

# 2️⃣ Current Setting in Your Screenshot

You currently have:

```id="dwffsn"
Internationalization → Disabled
```

This means:

* Keycloak uses **only the default language**
* No language switching is available
* UI messages are not translated

The default language is usually **English**.

---

# 3️⃣ What Happens When You Enable It

If you enable:

```id="jvgkpl"
Internationalization → Enabled
```

Then you can configure:

* Supported languages
* Default language
* Language switcher on login page

Example supported languages:

```
English
Spanish
French
German
Bengali
```

Then the login page might show:

```
Language: English ▼
```

Users can switch language.

---

# 5️⃣ Where Localization Applies

Localization affects these Keycloak pages:

| Page           | Example                   |
| -------------- | ------------------------- |
| Login page     | Username / Password       |
| Account page   | Profile / Password change |
| Error messages | Invalid credentials       |
| Email messages | Password reset email      |

---

# 6️⃣ Custom Translations

Developers can override translations.

Example custom message file:

```
themes/mytheme/login/messages/messages_bn.properties
```

Example content:

```
username=ব্যবহারকারীর নাম
password=পাসওয়ার্ড
login=লগইন
```

Then the login page appears in **Bengali**.

---

# 7️⃣ When Localization Is Used

Localization is important for:

* international applications
* banking systems
* government portals
* multi-country platforms

Example:

```
USA users → English
France users → French
Spain users → Spanish
```

---

# 8️⃣ Do You Need It Now?

```
Disabled is fine
```

You normally enable localization when building **production applications with global users**.
