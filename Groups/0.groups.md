Your screen shows:

```
No groups in this realm
```

This means **no groups have been created yet**.

Let’s explain what **Groups** are and why they are useful.

---

# 1️⃣ What a Group Is

A **Group** is a way to **organize users together** and assign **roles/permissions** to many users at once.

Instead of assigning roles to each user individually, you assign them to a group.

Example:

```
Group → ADMIN
Users → saddam, rahim, karim
```

All users in the group automatically get the same permissions.

---

# 2️⃣ Example in a Banking / Microservice System

Suppose your system has these user types:

| Group    | Description           |
| -------- | --------------------- |
| ADMIN    | System administrators |
| CUSTOMER | Bank customers        |
| EMPLOYEE | Bank staff            |
| MANAGER  | Branch managers       |

If a user joins **CUSTOMER group**, they automatically get customer permissions.

---

# 3️⃣ Example Structure (Hierarchy)

Groups can also be **nested**.

Example:

```
BANK
 ├── CUSTOMERS
 ├── EMPLOYEES
 │     ├── TELLERS
 │     └── MANAGERS
 └── ADMINS
```

This helps manage large organizations.

---

# 4️⃣ Why Groups Are Useful

Without groups:

```
User → assign role manually
User → assign role manually
User → assign role manually
```

With groups:

```
Create group → assign role once
Add users to group
```

Much easier to manage.

---

# 5️⃣ How Groups Work with Roles

Example:

Group:

```
CUSTOMER
```

Role assigned to group:

```
VIEW_ACCOUNT
TRANSFER_MONEY
```

Any user added to the group automatically receives those roles.

---

# 6️⃣ How to Create a Group

On your page click:

```
Create group
```

Example group name:

```
customers
```

Then:

```
Groups → customers → Role mapping
```

Add roles like:

```
USER
ACCOUNT_VIEW
```

---

# 7️⃣ How This Works in Your Spring Boot Microservices

When a user logs in:

```
User
 ↓
Keycloak
 ↓
JWT token created
```

Inside the token:

```
groups: ["customers"]
roles: ["USER"]
```

Your **Spring Boot service** reads these roles to allow or deny access.

Example:

```java
@PreAuthorize("hasRole('ADMIN')")
```

---

# 8️⃣ Difference Between Groups and Roles

| Feature              | Role     | Group  |
| -------------------- | -------- | ------ |
| Permission           | Yes      | No     |
| Organization         | No       | Yes    |
| Assign to many users | Indirect | Direct |

Best practice:

```
Group → contains users
Role → contains permissions
```
