ব্যাংকিং সিস্টেমে সাধারণত একটাই পদ্ধতি ব্যবহার করা হয় না। বেশিরভাগ ব্যাংক **multiple identity sources + central IAM** ব্যবহার করে। অনেক ক্ষেত্রে **Keycloak**, Okta, ForgeRock বা similar IAM ব্যবহৃত হয়।

আমি ব্যাংকের common architecture explain করছি।

---

# 🏦 Banking Identity Architecture (Typical)

```
Customers (Mobile / Web)
        │
        ▼
Bank IAM / Keycloak
        │
 ┌──────┼────────┐
 │      │        │
 ▼      ▼        ▼
Customer DB   LDAP/AD   External IdP
(core banking) employees social login
```

এখানে বিভিন্ন user type আলাদা source থেকে আসে।

---

# 1️⃣ Customers (Internet / Mobile Banking)

Customer data সাধারণত থাকে:

```
Core Banking System
```

বা

```
Customer Database
```

Flow:

```
Customer
   │
   ▼
IAM (Keycloak)
   │
   ▼
Customer DB / Auth Service
   │
   ▼
JWT Token
```

এখানে অনেক সময় ব্যবহার করা হয়:

* **custom authentication service**
* **OIDC / OAuth2 token issuance**

---

# 2️⃣ Bank Employees

Employee login সাধারণত:

```
Active Directory / LDAP
```

Flow:

```
Employee
   │
   ▼
Keycloak
   │
   ▼
Active Directory
```

এটা **User Federation**।

---

# 3️⃣ Third-party Integration

Open Banking / partner system:

```
Fintech apps
Payment gateways
```

এখানে ব্যবহার হয়:

* **OAuth 2.0**
* API gateway
* client credentials flow

---

# 4️⃣ Typical Bank Setup

| User Type | Storage                 |
| --------- | ----------------------- |
| Customers | Core banking DB         |
| Employees | LDAP / Active Directory |
| Partners  | OAuth client            |

IAM layer:

```
Keycloak / ForgeRock / Okta
```

---

# 🔑 Important Banking Principles

Banking systems usually require:

* MFA (OTP / hardware token)
* strong authentication
* audit logging
* session monitoring
* centralized identity

---

✅ **Short Answer**

ব্যাংকে সাধারণত:

* Employees → LDAP / AD federation
* Customers → Core banking database
* Partners → OAuth2 clients

সবকিছু **central IAM (যেমন Keycloak)** এর মাধ্যমে token issue করে।

---

যদি তুমি চাও, আমি তোমাকে দেখাতে পারি:

**Bank-level IAM architecture (Keycloak + Core Banking + API Gateway + Microservices)**

এটা বুঝলে পুরো banking authentication system পরিষ্কার হয়ে যাবে।
