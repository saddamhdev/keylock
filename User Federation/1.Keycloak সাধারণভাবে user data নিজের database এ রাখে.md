ভালো প্রশ্ন 👍
**Keycloak** সাধারণভাবে user data **নিজের database এ রাখে**।

---

# 1️⃣ Default User Storage

Keycloak default ভাবে ব্যবহার করে:

```text
Relational Database
```

যেমন:

* PostgreSQL
* MySQL
* MariaDB
* Oracle
* SQL Server

Production এ সবচেয়ে বেশি ব্যবহার হয় **PostgreSQL**।

---

# 2️⃣ Keycloak এর Database এ কী কী থাকে

Keycloak database এ শুধু user না, আরো অনেক data থাকে।

Example:

| Data        | Description            |
| ----------- | ---------------------- |
| Users       | username, email        |
| Credentials | password hash          |
| Roles       | user roles             |
| Groups      | user groups            |
| Clients     | OAuth clients          |
| Tokens      | refresh token metadata |
| Sessions    | login sessions         |

---

# 3️⃣ Example Table

Keycloak database এ কিছু important table:

```text
USER_ENTITY
CREDENTIAL
USER_ROLE_MAPPING
REALM
CLIENT
USER_SESSION
```

Example:

```text
USER_ENTITY
 ├── id
 ├── username
 ├── email
 └── created_timestamp
```

Password plain text থাকে না।

Stored as:

```text
hashed password
```

---

# 4️⃣ Development Mode

যদি তুমি docker দিয়ে run করো:

```bash
start-dev
```

তখন Keycloak use করে:

```text
H2 embedded database
```

এইটা testing এর জন্য।

Production এ ব্যবহার করা উচিত না।

---

# 5️⃣ Production Architecture

Production setup সাধারণত এমন হয়:

```text
Keycloak
   │
   ▼
PostgreSQL Database
```

Example:

```text
Keycloak Server
        │
        ▼
PostgreSQL
        │
        ├── users
        ├── roles
        ├── sessions
        └── clients
```

---

# 6️⃣ External User Storage Option

Keycloak চাইলে user external system থেকেও নিতে পারে।

Example:

```text
LDAP
Active Directory
Kerberos
```

তখন user database থাকে:

```text
Company Directory
```

Keycloak শুধু authentication proxy হয়।

---

# 🔑 Simple Summary

| Storage Type | Use                   |
| ------------ | --------------------- |

---

✅ **Short Answer**

Keycloak সাধারণভাবে **নিজের relational database (যেমন PostgreSQL)** এ user data store করে।

---

যদি চাও, আমি তোমাকে দেখাতে পারি **Keycloak database schema (important tables + relations)** — এটা বুঝলে Keycloak architecture অনেক clear হয়ে যাবে।
