তুমি যে স্ক্রিনটা দেখাচ্ছো সেটা **Keycloak** এর **User Federation** section।

এটা **Identity Provider (Google, GitHub)** থেকে আলাদা জিনিস।

এখানে Keycloak **external user database এর সাথে connect করে**।

---

# 🔐 User Federation কী

User Federation মানে:

```text
Keycloak user data নিজের database এ রাখবে না
```

বরং user থাকবে:

* LDAP
* Active Directory
* Kerberos

এবং Keycloak শুধু **authentication bridge** হিসেবে কাজ করবে।

---

# 🧠 Flow

```text
User
 │
 ▼
Keycloak Login
 │
 ▼
LDAP / Active Directory
 │
 ▼
User Verified
 │
 ▼
Keycloak JWT Token
```

---

# 1️⃣ LDAP Provider

LDAP = **Lightweight Directory Access Protocol**

এটা সাধারণত corporate user directory।

Example systems:

* OpenLDAP
* Microsoft Active Directory
* FreeIPA

User store example:

```text
cn=users
 ├── saddam
 ├── rahim
 ├── karim
```

Keycloak login verify করবে LDAP দিয়ে।

---

# 2️⃣ Kerberos Provider

Kerberos হলো **network authentication protocol**।

Enterprise systems এ ব্যবহার হয়।

Example:

```text
Windows Domain Login
```

User computer login করলে:

```text
AD → Kerberos ticket
```

Keycloak সেটা verify করতে পারে।

---

# 3️⃣ Identity Provider vs User Federation

অনেকে এই দুইটা confuse করে।

| Feature      | Identity Provider | User Federation        |
| ------------ | ----------------- | ---------------------- |
| Purpose      | external login    | external user database |
| Example      | Google, GitHub    | LDAP, AD               |
| User storage | external          | external               |
| Protocol     | OAuth2 / OIDC     | LDAP / Kerberos        |

---

# Example

### Identity Provider

```text

```

---

### User Federation

```text

```
