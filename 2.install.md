Make sure you have:

```bash
wsl --list --verbose
```

Inside WSL:

```bash
docker --version
```

If Docker not found → install **Docker Desktop for Windows** and enable:

* ✅ WSL integration
* ✅ Your Linux distro

---

## 🚀 Install & Run Keycloak on port **6062**

### 🔹 Step 1: Pull Keycloak image

```bash
docker pull quay.io/keycloak/keycloak:latest
```

---

### 🔹 Step 2: Run Keycloak (DEV mode)

```bash
docker run -d \
  --name keycloak \
  -p 6062:8080 \
  -e KEYCLOAK_ADMIN=admin \
  -e KEYCLOAK_ADMIN_PASSWORD=admin123 \
  quay.io/keycloak/keycloak:latest \
  start-dev
```

✅ What this does:

* Runs Keycloak
* Internal port `8080` → exposed as `6062`
* Admin user created

---

### 🔹 Step 3: Verify container

```bash
docker ps
```

You should see:

```
0.0.0.0:6062->8080/tcp
```

## 🧪 Stop / Start later

```bash
docker stop keycloak
docker start keycloak
```

Remove completely:

```bash
docker rm -f keycloak
```

---

## 📁 Optional: Persistent data (recommended)

If you don’t want users/realms deleted after restart:

```bash
docker run -d \
  --name keycloak \
  -p 6062:8080 \
  -v keycloak_data:/opt/keycloak/data \
  -e KEYCLOAK_ADMIN=admin \
  -e KEYCLOAK_ADMIN_PASSWORD=admin123 \
  quay.io/keycloak/keycloak:latest \
  start-dev
```
