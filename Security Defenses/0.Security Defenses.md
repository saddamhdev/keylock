You are in **Realm Settings → Security Defenses → Headers** in **Keycloak**.
This section configures **HTTP security headers** that protect Keycloak’s web pages (login page, account page, admin console) from common web attacks.

Think of these as **browser security rules** sent with every response.

---

# 1️⃣ X-Frame-Options

Current value:

```
SAMEORIGIN
```

**Purpose:** Protects against **Clickjacking attacks**.

Clickjacking example:

```
Attacker site loads your login page inside an invisible iframe
User clicks buttons without knowing
```

`SAMEORIGIN` means:

```
Only pages from the same domain can embed this page in an iframe
```

So other websites **cannot embed the Keycloak login page**.

---

# 2️⃣ Content Security Policy (CSP)

Current value:

```
frame-src 'self'; frame-ancestors 'self'; object-src 'none';
```

This is one of the **most important browser security protections**.

It controls **what external resources the page can load**.

Meaning of each part:

| Directive              | Meaning                            |
| ---------------------- | ---------------------------------- |
| frame-src 'self'       | Only allow frames from same origin |
| frame-ancestors 'self' | Only same site can embed the page  |
| object-src 'none'      | Disable Flash / plugins            |

This helps prevent:

* XSS attacks
* malicious scripts
* malicious embedded content

---

# 3️⃣ Content-Security-Policy-Report-Only

Currently empty.

If configured, the browser will:

```
Report violations but not block them
```

Used for **testing CSP rules** before enforcing them.

---

# 4️⃣ X-Content-Type-Options

Value:

```
nosniff
```

Prevents browsers from guessing file types.

Example attack:

```
Attacker uploads file disguised as image
Browser interprets it as script
Script executes
```

`nosniff` stops that.

---

# 5️⃣ X-Robots-Tag

Value:

```
none
```

This tells search engines:

```
Do NOT index this page
```

Important because **login pages should never appear in search engines**.

---

# 6️⃣ HTTP Strict Transport Security (HSTS)

Value:

```
max-age=31536000; includeSubDomains
```

Purpose:

```
Force browser to always use HTTPS
```

Meaning:

| Part              | Meaning                   |
| ----------------- | ------------------------- |
| max-age=31536000  | 1 year enforcement        |
| includeSubDomains | Applies to all subdomains |

If a user tries:

```
http://your-domain
```

Browser automatically switches to:

```
https://your-domain
```

This prevents **man-in-the-middle attacks**.

---

# 7️⃣ Referrer Policy

Value:

```
no-referrer
```

Controls how much **referrer information is sent to other websites**.

`no-referrer` means:

```
Never send referrer URL to other sites
```

This protects **user privacy and sensitive URLs**.

---

# 8️⃣ Why These Settings Exist

These headers protect against common web vulnerabilities:

| Attack          | Protection              |
| --------------- | ----------------------- |
| Clickjacking    | X-Frame-Options         |
| XSS             | Content Security Policy |
| MIME confusion  | X-Content-Type-Options  |
| Search indexing | X-Robots-Tag            |
| MITM            | HSTS                    |
| Data leakage    | Referrer Policy         |
