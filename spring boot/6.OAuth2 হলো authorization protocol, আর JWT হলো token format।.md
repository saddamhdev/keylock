তোমার প্রশ্নটা খুব গুরুত্বপূর্ণ: **OAuth2 এর সাথে JWT কীভাবে connect হয়?**
সহজভাবে বললে:

> OAuth2 হলো **authorization protocol**, আর JWT হলো **token format**।

---

# 1️⃣ Basic Concept

* **OAuth 2.0**
  → বলে **কীভাবে access token দেওয়া হবে**।

* **JSON Web Token**
  → বলে **token এর ভিতরের structure কেমন হবে**।

মানে:

```text
OAuth2 → rules
JWT → token format
```

---

# 2️⃣ OAuth2 Token সবসময় JWT না

OAuth2 specification বলে না token কেমন হবে।

Token হতে পারে:

| Token Type   | Description      |
| ------------ | ---------------- |
| Opaque Token | random string    |
| JWT Token    | structured token |

Example opaque token:

```
a83hdh72hshs73hdhsh
```

Example JWT:

```
eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9...
```

আজকাল microservice architecture এ **JWT বেশি ব্যবহার হয়**।

---

# 3️⃣ OAuth2 + JWT Flow

ধরো login হলো।

Flow:

```text
Client
  │
  ▼
Authorization Server
(Keycloak)
  │
  ▼
Generate JWT Access Token
  │
  ▼
Client calls API with token
```

Authorization server হিসেবে সাধারণত ব্যবহার করা হয়
**Keycloak**।

---

# 4️⃣ JWT Structure

JWT token তিনটা অংশে থাকে:

```
HEADER.PAYLOAD.SIGNATURE
```

Example:

```
eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9
.
eyJzdWIiOiIxMjM0NSIsInJvbGUiOiJBRE1JTiJ9
.
signature
```

---

# 5️⃣ JWT Payload Example

```json
{
 "iss": "http://auth-server/realms/banking",
 "sub": "12345",
 "preferred_username": "saddam",
 "realm_access": {
   "roles": ["CUSTOMER"]
 },
 "exp": 1712345678
}
```

এখানে থাকে:

* user id
* roles
* expiration
* issuer

---

# 6️⃣ Service কীভাবে JWT verify করে

Microservice API request পেলে:

```
Authorization: Bearer <token>
```

Service check করে:

1️⃣ Signature valid কিনা
2️⃣ Token expire হয়েছে কিনা
3️⃣ Issuer ঠিক কিনা

Signature verify হয় **Keycloak public key** দিয়ে।

---

# 7️⃣ Spring Boot Example

Spring Boot config:

```yaml
spring:
  security:
    oauth2:
      resourceserver:
        jwt:
          issuer-uri: http://localhost:8080/realms/banking
```

এতে Spring Security automatically:

* JWT decode করে
* signature verify করে
* role read করে

# 9️⃣ কেন JWT popular

Microservices এ JWT popular কারণ:

✔ Stateless
✔ Fast verification
✔ DB call লাগে না
✔ Scalable

# 🔑 Summary

| Concept  | Meaning                       |
| -------- | ----------------------------- |
| OAuth2   | Access authorization protocol |
| JWT      | Token format                  |
| Keycloak | OAuth2 + JWT provider         |

Flow:

```
Login → OAuth2 → JWT token → API call → JWT verify
```

OAuth2 access token হিসেবে **JWT ব্যবহার করে**, যাতে service গুলো সহজে verify করতে পারে।
