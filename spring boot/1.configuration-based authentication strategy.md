তোমার দেওয়া config:

```yaml
features:
  auth:
    provider: keycloak
```

এটা আসলে **configuration-based authentication strategy**।
মানে application runtime এ decide করবে **কোন authentication system ব্যবহার করবে**।

এই pattern কে সাধারণত বলে **Auth Provider Switch / Strategy Pattern**।

---

# 1️⃣ Config এর Meaning

```yaml
features:
  auth:
    provider: keycloak
```

মানে:

| Value    | Meaning                    |
| -------- | -------------------------- |
| keycloak | Keycloak authentication    |
| internal | Internal DB authentication |
| none     | Security disabled          |

Example:

```yaml
features:
  auth:
    provider: internal
```

তখন login system internal database দিয়ে চলবে।

---

# 2️⃣ Spring Boot এ এটা পড়া হয়

Spring Boot এ config read করা হয় `@ConfigurationProperties` দিয়ে।

Example:

```java
@ConfigurationProperties(prefix = "features.auth")
public class AuthFeatureProperties {

    private String provider;

    public String getProvider() {
        return provider;
    }

    public void setProvider(String provider) {
        this.provider = provider;
    }
}
```

---

# 3️⃣ Conditional Security Configuration

তারপর Spring Boot decide করে কোন security enable হবে।

### Keycloak Config

```java
@Configuration
@ConditionalOnProperty(
        prefix = "features.auth",
        name = "provider",
        havingValue = "keycloak"
)
public class KeycloakSecurityConfig {

    @Bean
    SecurityFilterChain filterChain(HttpSecurity http) throws Exception {

        http
            .authorizeHttpRequests(auth -> auth.anyRequest().authenticated())
            .oauth2ResourceServer(oauth -> oauth.jwt());

        return http.build();
    }
}
```

---

### Internal Auth Config

```java
@Configuration
@ConditionalOnProperty(
        prefix = "features.auth",
        name = "provider",
        havingValue = "internal"
)
public class InternalSecurityConfig {

    @Bean
    SecurityFilterChain filterChain(HttpSecurity http) throws Exception {

        http
            .authorizeHttpRequests(auth -> auth.anyRequest().authenticated())
            .formLogin();

        return http.build();
    }
}
```

# 4️⃣ Runtime Flow

Application start হলে:

```text
Spring Boot
     │
     ▼
Read application.yml
     │
     ▼
features.auth.provider
     │
     ▼
Load Security Config
```

Example:

```text
provider = keycloak
```

তখন load হবে:

```
KeycloakSecurityConfig
```

# 6️⃣ Enterprise Microservice Pattern

অনেক enterprise system এ থাকে:

```yaml
features:
  auth:
    provider: keycloak
  audit:
    enabled: true
  rate-limit:
    enabled: true
```

এভাবে **feature flags** control করা হয়।

---

# 🔑 Summary

`features.auth.provider` = **authentication provider switch**

| Value    | System            |
| -------- | ----------------- |
| keycloak | OAuth2 / Keycloak |
| internal | Database login    |
| none     | No security       |

Spring Boot `@ConditionalOnProperty` দিয়ে decide করে কোন config load হবে।
