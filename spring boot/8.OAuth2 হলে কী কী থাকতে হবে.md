সংক্ষিপ্ত উত্তর: **না, শুধু login নিয়ে token return করলেই সেটাকে OAuth2 বলা যায় না।**
ওটা হতে পারে **custom token authentication**। OAuth2 হতে হলে কিছু নির্দিষ্ট standard follow করতে হয়।

---

## 1️⃣ OAuth2 হলে কী কী থাকতে হবে

**OAuth 2.0** একটি **standard protocol**। তাই OAuth2 system-এ সাধারণত এই জিনিসগুলো থাকে:

1. **Authorization Server** (যেমন Keycloak)
2. **Client**
3. **Resource Server (API)**
4. **Standard endpoints**
5. **Grant types**
6. **Access token**

---

## 2️⃣ OAuth2 Standard Endpoint

OAuth2 server সাধারণত এই endpoint দেয়:

```text
/oauth/token
/authorize
/token
/.well-known/openid-configuration
```

Example (Keycloak):

```text
/realms/banking/protocol/openid-connect/token
```

---

## 3️⃣ OAuth2 Request Structure

Token request সাধারণত এভাবে হয়:

```http
POST /token
Content-Type: application/x-www-form-urlencoded
```

Body:

```text
grant_type=password
client_id=my-client
client_secret=secret
username=saddam
password=123456
```

এই structure OAuth2 standard।

---

## 4️⃣ OAuth2 Roles (Actors)

OAuth2-এ চারটা actor থাকে:

| Actor                | Meaning        |
| -------------------- | -------------- |
| User                 | Resource owner |
| Client               | App            |
| Authorization Server | Login server   |
| Resource Server      | API            |

Example:

```text
User → React App → Keycloak → Account API
```

---

## 5️⃣ Simple Login API Example

ধরো তুমি নিজের API বানালে:

```http
POST /login
{
  "username": "saddam",
  "password": "123456"
}
```

Response:

```json
{
 "token": "abc123"
}
```

এটা **OAuth2 না**।

এটা শুধু **custom authentication API**।

---

## 6️⃣ OAuth2 Example

OAuth2 flow:

```text
Client
   │
   ▼
Authorization Server
   │
   ▼
Access Token
   │
   ▼
API
```

Authorization server হতে পারে
**Keycloak**

---

## 7️⃣ OAuth2 + JWT

OAuth2 access token হিসেবে সাধারণত **JSON Web Token** ব্যবহার করা হয়।

Flow:

```text
Login → OAuth2 server → JWT token → API call
```
