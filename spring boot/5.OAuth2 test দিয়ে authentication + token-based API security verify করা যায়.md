# 🧪 OAuth2 Test দিয়ে কী কী Verify করা যায়

ধরো তুমি **Keycloak** ব্যবহার করছো।

Postman দিয়ে token endpoint call করলে তুমি verify করতে পারো:

## 1️⃣ User Authentication

User credentials ঠিক কিনা।

Example:

```text
username = saddam
password = 123456
```

Result:

* ✔ Correct → token পাওয়া যাবে
* ❌ Wrong → 401 Unauthorized

---

## 2️⃣ Client Configuration

এই client কি OAuth2 ব্যবহার করতে পারে?

Example:

```
client_id
client_secret
```

Verify হয়:

* client exist কিনা
* secret ঠিক কিনা

---

## 3️⃣ Token Generation

Test করতে পারো:

* access token create হচ্ছে কিনা
* refresh token আসছে কিনা
* expiry time ঠিক আছে কিনা

Example response:

```json
{
 "access_token": "...",
 "expires_in": 300
}
```

---

## 4️⃣ Role / Authorization

Token নিয়ে API call করলে verify করা যায়:

```text
role = CUSTOMER
```

API:

```
POST /loan/approve
```

Result:

* ❌ access denied

Example:

```
role = MANAGER
```

Result:

* ✔ access allowed

---

## 5️⃣ Token Expiration

Test করা যায়:

```
accessTokenLifespan
```

Example:

```
token expire after 5 min
```

৫ মিনিট পরে API call করলে:

```
401 Unauthorized
```

---

## 6️⃣ Service Security

Verify করা যায়:

* API token ছাড়া access করা যায় কিনা
* invalid token reject হচ্ছে কিনা

Example:

```
Authorization: Bearer invalid_token
```

Result:

```
401 Unauthorized
```
