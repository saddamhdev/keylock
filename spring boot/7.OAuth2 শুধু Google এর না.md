**OAuth2 শুধু Google এর না।**

| Platform  | Use                       |
| --------- | ------------------------- |

| GitHub    | GitHub login              |
| Microsoft | Microsoft account login   |

| Azure AD        | Microsoft identity |

# ⚠️ Important

অনেকেই ভুল ভাবে:

```text
OAuth2 = Google Login
```

আসলে:

```text
Google Login = OAuth2 + OpenID Connect
```
