তুমি জানতে চাও **OAuth2 এর সাথে OpenID কীভাবে কাজ করে**।
এটা বুঝতে হলে আগে দুটার কাজ আলাদা বুঝতে হবে।

---

# 1️⃣ OAuth2 কী করে

**OAuth 2.0**

OAuth2 এর কাজ:

> **API access permission দেওয়া**

মানে OAuth2 বলে:

```text
এই client কি এই API access করতে পারবে?
```

Example:

```text
Client → Access Account API
```

OAuth2 token দেয়:

```text
access_token
```

কিন্তু OAuth2 বলে না:

```text
User কে?
```

---

# 2️⃣ OpenID Connect কী করে

**OpenID Connect**

OpenID Connect (OIDC) OAuth2 এর উপর তৈরি।

এটা বলে:

```text
User কে?
```

মানে **authentication + identity**।

---

# 3️⃣ OAuth2 + OpenID Connect Together

যখন system login করে তখন normally:

```text
OAuth2 + OpenID Connect
```

দুটো একসাথে কাজ করে।

Flow:

```text
Client
 │
 ▼
Authorization Server
 │
 ▼
Login
 │
 ▼
Token Response
```

---

# 4️⃣ Token Types

OIDC ব্যবহার করলে তিন ধরনের token পাওয়া যায়:

| Token         | Purpose       |
| ------------- | ------------- |
| Access Token  | API call      |
| ID Token      | user identity |
| Refresh Token | new token     |

Example response:

```json
{
 "access_token": "...",
 "id_token": "...",
 "refresh_token": "..."
}
```

---

# 5️⃣ ID Token কী

ID token হলো JWT।

**JSON Web Token**

Example payload:

```json
{
 "sub": "12345",
 "name": "Saddam",
 "email": "saddam@mail.com"
}
```

এখানে user information থাকে।

# 6️⃣ Real Example

ধরো তুমি ব্যবহার করছো:

Login flow:

```text
React App
   │
   ▼
Keycloak Login
   │
   ▼
OAuth2 Authorization
   │
   ▼
OpenID Identity
   │
   ▼
```

# 8️⃣ Simple Analogy

ধরো airport।

| Real World    | System |
| ------------- | ------ |
| Passport      | OpenID |
| Boarding pass | OAuth2 |

Explanation:

```text
OpenID → তুমি কে
OAuth2 → কোথায় যেতে পারবে
```

# 🔑 Summary

| Concept        | Work           |
| -------------- | -------------- |
| OAuth2         | Authorization  |
| OpenID Connect | Authentication |
| JWT            | Token format   |

Flow:

```text
Login → OpenID identify user
       ↓
OAuth2 give access
       ↓
API access with token
```

✅ **Short Answer**

OpenID Connect = OAuth2 এর উপর তৈরি **authentication layer**।
OAuth2 permission দেয়, OpenID user identity দেয়।
