তুমি যদি **OAuth2 test করতে চাও**, তাহলে সাধারণত ২টা সহজ উপায় আছে:

1️⃣ **Postman দিয়ে test**
2️⃣ **curl / API request দিয়ে test**

এখানে আমি **Keycloak + OAuth2** example দিয়ে দেখাচ্ছি।

---

# 1️⃣ OAuth2 Test করার সবচেয়ে সহজ method

ধরো তুমি ব্যবহার করছো **Keycloak**।

তখন OAuth2 token endpoint হয়:

```
http://localhost:8080/realms/{realm}/protocol/openid-connect/token
```

Example:

```
http://localhost:8080/realms/banking-dev/protocol/openid-connect/token
```

---

# 2️⃣ Postman দিয়ে OAuth2 Token Test

### Request

POST

```
http://localhost:8080/realms/banking-dev/protocol/openid-connect/token
```

### Body (x-www-form-urlencoded)

```
grant_type=password
client_id=banking-backend
client_secret=dev-backend-secret
username=saddam
password=123456
```

---

# 3️⃣ Expected Response

Keycloak return করবে:

```json
{
 "access_token": "eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9...",
 "expires_in": 300,
 "refresh_token": "eyJhbGciOi..."
}
```

এটাই OAuth2 **access token**।

---

# 4️⃣ Token দিয়ে API Test

ধরো তোমার Spring Boot API আছে:

```
GET http://localhost:8081/accounts
```

Header add করবে:

```
Authorization: Bearer eyJhbGciOi...
```

Postman এ:

```
Headers
Authorization : Bearer <access_token>
```

---

# 5️⃣ Spring Boot Service কী করবে

যদি Spring Security configure করা থাকে:

```yaml
spring:
  security:
    oauth2:
      resourceserver:
        jwt:
          issuer-uri: http://localhost:8080/realms/banking-dev
```

তাহলে Spring Boot automatically:

* token verify করবে
* signature check করবে
* role check করবে

Manual code লাগবে না।

---

# 6️⃣ curl দিয়ে OAuth2 Test

```bash
curl -X POST \
http://localhost:8080/realms/banking-dev/protocol/openid-connect/token \
-H "Content-Type: application/x-www-form-urlencoded" \
-d "grant_type=password" \
-d "client_id=banking-backend" \
-d "client_secret=dev-backend-secret" \
-d "username=saddam" \
-d "password=123456"
```

---

# 7️⃣ OAuth2 Test Flow

```
Postman
   │
   ▼
Keycloak Token Endpoint
   │
   ▼
JWT Access Token
   │
   ▼
API Request
   │
   ▼
Spring Boot verifies token
```
