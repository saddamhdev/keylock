তুমি যে স্ক্রিনটা দেখিয়েছো সেটা **Keycloak** এর **Authentication → Flows** পেজ।

এখানে **login process কীভাবে হবে সেটা define করা হয়**।
মানে Keycloak এ user login করলে **step-by-step authentication logic** এই flows দিয়ে control করা হয়।

---

# Authentication Flow কী?

Authentication flow মানে:

```text
Login process এর step sequence
```

Example:

```
User login
   │
   ▼
Username + Password
   │
   ▼
OTP verification
   │
   ▼
Success
```

এই logic Keycloak এ **Authentication Flow** দিয়ে configure করা হয়।

---

# Screen এ যে flows দেখাচ্ছে

আমি এক এক করে explain করছি।

---

# 1️⃣ browser flow

```
browser
```

Used by:

```
Browser login
```

এটা সবচেয়ে common login flow।

Example:

```
User
 │
 ▼
Keycloak Login Page
 │
 ▼
Username + Password
 │
 ▼
Success
```

Browser based login যেমন:

* web app
* admin console
* SSO login

---

# 2️⃣ clients flow

```
clients
```

Used for:

```
Client authentication
```

এটা use হয় যখন:

```
Application authenticate করে
```

Example:

```
service
   │
   ▼
Keycloak
   │
   ▼
client_id + client_secret
```

Use case:

* machine-to-machine authentication
* service accounts

---

# 3️⃣ direct grant flow

```
direct grant
```

Used for:

```
username + password API login
```

Example request:

```
POST /token
grant_type=password
username=user
password=pass
```

এটা **OAuth2 password grant** flow।

Normally use হয়:

* mobile apps
* CLI tools
* Postman testing

---

# 4️⃣ docker auth flow

```
docker auth
```

Used for:

```
Docker registry authentication
```

Example:

```
docker login registry
```

Keycloak verify করে।

Mostly use হয়:

* private container registry
* DevOps pipelines

---

# 5️⃣ first broker login flow

```
first broker login
```

Use হয় যখন user first time social login করে।

Example:

```
Login with Google
```

Flow:

```
Google
   │
   ▼
Keycloak
   │
   ▼
Create local account
```

এটা account linking handle করে।

---

# 6️⃣ registration flow

```
registration
```

Use হয় যখন user:

```
new account create করে
```

Steps example:

```
User registration
   │
   ▼
Form fill
   │
   ▼
Email verification
```

---

# 7️⃣ reset credentials flow

```
reset credentials
```

Use হয়:

```
Forgot password
```

Flow example:

```
User forgot password
   │
   ▼
Email link
   │
   ▼
New password
```
