ভালো প্রশ্ন 👍
তুমি জানতে চাও **Keycloak user table এবং service (যেমন user-service) table এর data কীভাবে sync হয়**।

সংক্ষিপ্তভাবে বললে:
**সাধারণত automatic sync হয় না।**
বরং **ID mapping + event/API দিয়ে sync করা হয়।**

আমি সবচেয়ে common ৩টা pattern দেখাচ্ছি।

---

# 1️⃣ Pattern 1 — User ID Mapping (সবচেয়ে common)

Keycloak user তৈরি হলে তার একটা **ID** থাকে।

Example Keycloak user:

```json
{
 "id": "9f8a3c21",
 "username": "saddam",
 "email": "saddam@email.com"
}
```

User-service database:

```
users
-------------------------
id
keycloak_id
email
name
phone
```

Example:

```
keycloak_id = 9f8a3c21
```

Flow:

```text
Keycloak
   │
   ▼
JWT token
   │
   ▼
sub = 9f8a3c21
   │
   ▼
User Service
```

Service match করে:

```sql
SELECT * FROM users
WHERE keycloak_id = '9f8a3c21';
```

এটা **synchronization না, mapping**।

---

# 2️⃣ Pattern 2 — User Creation Event Sync

User Keycloak এ তৈরি হলে backend service এ user create করা হয়।

Flow:

```
User registers
   │
   ▼
Keycloak
   │
   ▼
Event: USER_CREATED
   │
   ▼
User Service API
   │
   ▼
Create user record
```

Keycloak event listener দিয়ে করা যায়।

Example event:

```
REGISTER
UPDATE_PROFILE
RESET_PASSWORD
```

---

# 3️⃣ Pattern 3 — First Login Sync

User প্রথম login করলে service এ user create হয়।

Flow:

```
User login
   │
   ▼
Keycloak
   │
   ▼
JWT token
   │
   ▼
User Service
   │
   ▼
Check user exists?
   │
   ├─ yes → continue
   └─ no → create user
```

Example code logic:

```java
if(userRepository.findByKeycloakId(sub) == null){
    createUser();
}
```

# 4️⃣ Enterprise Banking Pattern

Banking / fintech systems সাধারণত:

```
Keycloak
   │
   ▼
Identity (login)
   │
   ▼
User Service
   │
   ▼
Customer Profile DB
```

Meaning:

| System       | Responsibility |
| ------------ | -------------- |
| Keycloak     | authentication |
| User Service | customer data  |
| Core banking | financial data |

---

# 5️⃣ Password Sync কেন হয় না

Password সাধারণত **Keycloak ছাড়া কোথাও থাকে না**।

Flow:

```
Password reset
   │
   ▼
Keycloak DB update
   │
   ▼
Services unaffected
```
