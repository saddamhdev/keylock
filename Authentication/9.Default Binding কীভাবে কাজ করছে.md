তুমি এখন **Realm settings → Login** পেজে আছো (screenshot অনুযায়ী)। নতুন Keycloak UI-তে **Authentication Bindings এখানে দেখায় না**। এজন্য তুমি পাচ্ছো না।

**Keycloak**-এর নতুন admin console-এ **Bindings সরানো হয়েছে এবং automatic default flow ব্যবহার করে** যদি তুমি custom কিছু না দাও।

আমি পরিষ্কার করে বুঝাই।

---

# 1️⃣ Default Binding কীভাবে কাজ করছে

Keycloak default ভাবে এই flows bind করে রাখে:

| Flow Type         | Default Flow        |
| ----------------- | ------------------- |
| Browser login     | `browser`           |
| API login         | `direct grant`      |
| User registration | `registration`      |
| Password reset    | `reset credentials` |

এইগুলো automatic।

---

# 2️⃣ কখন Binding change করতে হবে

Binding change দরকার হয় যখন তুমি **custom authentication flow** বানাও।

Example:

```
browser + OTP
browser + captcha
browser + device verification
```

তখন flow assign করতে হয়।

---

# 3️⃣ Flow assign কোথায় হয় (New UI)

নতুন Keycloak UI-তে assign হয় এখানে:

```
Authentication
   ↓
Flows
   ↓
Select Flow
   ↓
Action → Bind flow
```

অথবা client level-এ override করা যায়।

---

# 4️⃣ Browser Login Flow এখন কী

তুমি এখন ব্যবহার করছো:

```
browser (Built-in)
```

এই flow এর ভিতরে থাকে:

```
Cookie
Username Password Form
Identity Provider Redirect
```

এটাই default login।

---

# 5️⃣ Direct Grant Flow

যদি তুমি Postman / API login করো:

```
POST /token
grant_type=password
```

তখন use হয়:

```
direct grant flow
```

---

# 6️⃣ Registration Flow

User signup করলে:

```
registration flow
```

---

# 7️⃣ Password Reset

Forgot password করলে:

```
reset credentials flow
```

---

# 8️⃣ তোমার বর্তমান setup ঠিক আছে

তুমি যা দেখাচ্ছো সেটাই normal configuration।

তোমাকে কিছু change করতে হবে না যদি না:

* OTP add করতে চাও
* MFA add করতে চাও
* captcha add করতে চাও

---

# 9️⃣ Bonus (Important)

তোমার screenshot-এ আছে:

```
User registration → OFF
```

মানে users signup করতে পারবে না।

Enable করতে চাইলে:

```
Realm settings → Login
User registration → ON
```

তুমি Binding option পাচ্ছো না কারণ:

* নতুন Keycloak UI-তে এটা hidden / automatic
* default flows already bind করা আছে
