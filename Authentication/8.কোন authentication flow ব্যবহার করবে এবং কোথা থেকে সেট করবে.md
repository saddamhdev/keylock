তুমি কোন **authentication flow** ব্যবহার করবে এবং কোথা থেকে সেট করবে—এটা Keycloak-এ খুব সহজভাবে control করা যায়। নিচে পরিষ্কার করে দিচ্ছি।

---

# 1️⃣ সাধারণ Login (Web / App Login)

সবচেয়ে common হলো **browser flow**।

এটা ব্যবহার হয় যখন:

* Web app login
* Admin login
* SSO login

Flow:

```text
User
 │
 ▼
Keycloak Login Page
 │
 ▼
Username + Password
 │
 ▼
JWT Token
```

এইটা default flow।

---

# 2️⃣ API / Mobile / Postman Login

যদি API দিয়ে login করো:

```
POST /token
grant_type=password
```

তখন ব্যবহার হয়:

```
direct grant flow
```

এটা API-based login।

---

# 3️⃣ Social Login

যদি ব্যবহার করো:

* Google login

তখন use হয়:

```
first broker login flow
```

registration flow

---

# 6️⃣ কোথা থেকে flow set করবে

Keycloak Admin Console এ গিয়ে:

```
Authentication
   ↓
Flows
```

এই page-এ সব flow দেখাবে।

কিন্তু কোন flow active হবে সেটা set করতে হবে এখানে:

```
Authentication
   ↓
Bindings
```

ওখানে দেখবে:

| Binding           | Flow         |
| ----------------- | ------------ |
| Browser Flow      | browser      |
| Direct Grant Flow | direct grant |
| Registration Flow | registration |

এখানে তুমি change করতে পারো।

---

# 7️⃣ Custom Flow তৈরি করা

তুমি চাইলে custom login flow বানাতে পারো।

Example:

```
Username + Password
      ↓
OTP
      ↓
Email verification
      ↓
Login success
```

Steps:

```
Authentication
   ↓
Flows
   ↓
Copy "browser"
   ↓
Edit
   ↓
Add execution
```

# ✔ Recommended Setup (Most Projects)

| Use Case       | Flow              |
| -------------- | ----------------- |
| Web login      | browser           |
| API login      | direct grant      |
| Signup         | registration      |
| Password reset | reset credentials |

---

✔ Summary

* Flow configure হয় → **Authentication → Flows**
* Flow bind হয় → **Authentication → Bindings**

---

যদি তুমি চাও, আমি দেখাতে পারি **Keycloak authentication flow ভিতরে কীভাবে execute হয় (Execution + Requirement)** — এটা বুঝলে flow configuration একদম clear হয়ে যাবে।
